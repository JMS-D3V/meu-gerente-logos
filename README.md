# meu-gerente-logos

Logos SVG de bancos e bandeiras de cartão consumidas pelo app
**Meu Gerente — Gestão Financeira** (Android).

## Estrutura

```
bancos/{codigoCompe}.svg     # COMPE BACEN (3 dígitos)
bandeiras/{nome}.svg         # nome lowercase (visa, mastercard, elo, etc)
```

## Servido via jsDelivr CDN

```
https://cdn.jsdelivr.net/gh/JMS-D3V/meu-gerente-logos@main/bancos/341.svg
https://cdn.jsdelivr.net/gh/JMS-D3V/meu-gerente-logos@main/bandeiras/visa.svg
```
